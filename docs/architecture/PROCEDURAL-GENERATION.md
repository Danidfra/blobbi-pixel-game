# Procedural generation

Everything visible is generated from seeds and drawn pixel by pixel: no sprite packs, no downloaded or AI-generated
raster assets. **IMPLEMENTED**. Core rules: `src/core/rng.ts`, `src/core/palette.ts`, `src/core/shade.ts`.

## 1. Randomness

- `stream(seed, ...keys)` gives an independent generator per purpose (cyrb128 hashing + sfc32, pure 32-bit integer
  math). Adding a feature means drawing from a **new key**, so existing sequences never shift.
- No `Math.random()`, no clocks in generation or simulation. Pixel-level detail is hashed from the position
  (`hash32`), so it is stable under regeneration.

## 2. Style rules

One top-left light; five-shade ramps derived from one base colour (shadows darker and cooler, highlights lighter and
warmer, `core/palette.ts`); banded shading, never gradients; a one-pixel outline (`core/shade.ts`). Every generator
follows them, so trees, rocks, houses, furniture, creatures and the Blobbi read as one artist.

## 3. Worlds

| Kind | Generator | Shape |
|---|---|---|
| `island` (phases 1–3) | `generateWorld` (`src/world/generate.ts`) | a bridged chain of islands |
| `turtle` (default) | `generateTurtleWorld` (`src/world/turtle-world.ts`) | one island on a turtle's shell |
| `manta` (M7) | `generateMantaWorld` (`src/carriers/manta-world.ts`) | one wide island on a manta's back |

The turtle pipeline: turtle genome → anatomy → the shell's top as an `Island` record → `rasterizeTerrain` (signed
distance → classes, elevation, paths) → beach bands become the shell RIM, head/neck/flippers/tail become SKIN, the
sea wraps the animal → hubs, a pond, meadows, paths (prow, pond, overlook, house) → `placeObjects` (houses, fences,
decor, groves, bushes, rocks, flowers, tufts) → ground dressing. Variants 1–3 generate the same island in its own
frame (Variant 0) and embed it into a larger carrier canvas (`src/carrier/turtle-carrier.ts`). Variant S (new
turtle worlds since 2026-10-11) runs the same pipeline on a shell top shrunk to 72 % at the same centre of the same
frame (`generateTurtleBase`), then fits the shell around that smaller island to about 40 % coverage.

The manta pipeline reuses the same terrain, path and placement code: the island is an oval fitted inside the manta's
still core with a sand beach; the core is SKIN (drawn from the body); the sea bands hug the core; the wing tips and
whip animate as sprites.

Terrain classes (`T` in `src/world/types.ts`): deep, water, shallow, foam, wet sand, sand, grass edge, grass, grass
patch, path, cliff face, dark grass, RIM (shell), SKIN (body), pond, pond edge, meadow, and since M7 moss, gravel,
clover. `WALKABLE` lists the ones a character can stand on.

## 4. Objects and creatures

Trees (4 trunks × 5 canopies × texture × fruit or blossom, with growth stages), bushes, flowers, grass tufts, rocks,
houses, bridges, fences, decor (`src/objects/`); furniture and decorations (`src/game/furniture-art.ts`); crops by
stage (`src/content/crops.ts` templates); the turtle (`src/turtle/turtle.ts`); whale and manta
(`src/carriers/`). Creatures separate species constants, a seeded genome (shape stream), cosmetics (a separate
stream), anatomy, pose and render, all pure functions.

## 5. The Blobbi

Not generated by this repository: the pixel Blobbi is the Blobbi kit's canonical V3 drawing rasterized with pixel-art
rules ([Blobbi identity](BLOBBI-IDENTITY.md)).

## 6. Growth (M7)

`growWorld(base, stage, version)` (`src/world/growth.ts`):

1. A plan from the base world: an allowed radius per angle (land may grow only over the carrier's free surface — the
   turtle's shell ring keeping a band of plates and the lip visible; the manta's back at least 6 × scale from its
   edge), a ring factor, and coast lobes per region at seeded bearings (turtle: round the compass; manta: east and
   west along the wings).
2. For each stage up to the target: the grown coastline (the base `Island` record × ring, plus the lobes as `cape`
   coast features, with the base terrain's own edge wobble); free-surface pixels inside it become land (coast band,
   or the region's biome ground); old shore bands now inland become plain grass; objects for that stage's regions
   are placed on that stage's terrain and appended.
3. The result keeps every base pixel that was land as land, every existing object's index and position, the turtle,
   the carrier, the island record, the hubs and paths.

Biomes: flower meadow (MEADOW), little woodland (dark grass), rocky garden (GRAVEL), shore turf (CLOVER), mushroom
grove (MOSS). See [World growth](../specifications/WORLD-GROWTH.md).

## 7. Versioning

| Version | Where | Meaning |
|---|---|---|
| `GROWTH_VERSION = 2` (reproduces 1 and 2) | `src/world/growth.ts`, saved in `growth.version` and each history entry | the growth generator; a change to its output needs a new version and keeping the old branch (v2 changed only the whale's object spacing) |
| `GENERATOR_VERSION = 'm6.0'` | `src/game/archipelago.ts`, saved as `generator` | the base world generator, for `CarrierRef` keys and compatibility records |
| shell variant (`variant=` in the identity) | `src/carrier/types.ts` | which turtle shell and island a world was made with; Variants 0–3 are pinned byte-identical (`tests/turtle-start.test.ts`), Variant S is the small start for new worlds |
| `SAVE_VERSION = 9` | `src/game/persistence.ts` | the save schema |

Pinned visual hashes (`tests/__snapshots__/`) catch any unintended change to existing generation.
