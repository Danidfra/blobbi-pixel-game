## B. Languages and readable text

See [I18N](../architecture/I18N.md) for the architecture. In short:

- English, Brazilian Portuguese and Spanish, complete: **801 interface messages + 874 content texts** (6 280 English
  words) per language, hand-written, typed keys, plurals, interpolation, English fallback, missing-key detection,
  noun phrases with gender and contractions. Browser detection (pt-* / es-* / else en), explicit choice kept, live
  switching, LANGUAGE in SETTINGS and on every title page (button or L). Other languages load as their own chunk.
- Everything a player reads is translated: title, carrier choice, naming, creation and intro lines, tips, quests,
  journal, goal box, building, house upgrades and styles, crafting and locked hints, bag, tools, resources, farming,
  cooking, fishing, the canoe, marine life, discoveries, notices, bubbles, errors, settings, account, save notices,
  confirmations, key and touch instructions. Not translated: ids, save fields, generated and typed island names, the
  developer lab and dev tools.
- **Readability**: menus, the title and HUD cards are drawn at screen resolution with a new hand-made readable pixel
  font (two sizes, lowercase, accents) for sentences; the 3×5 capitals stay for headings (now with accents). Phones
  at 667×375 get 2× menus (were 1×). Text on the title scene has a shadow. Low-contrast locked labels raised to the
  muted colour.
- **TEXT SIZE** small / normal / large (replaces MENU SCALE and LARGE HUD TEXT; the old setting carries over).

## C. Blobbi generations (investigation only)

See [Blobbi generation compatibility](../architecture/BLOBBI-GENERATION-COMPATIBILITY.md). V1 and V2 share the same
seed (address **and birth time**) and traits, differing only in adult artwork; V3 is a different procedural model with
an address-only seed. V2 is not "close to V3" in the code. Kit-based apps draw each Blobbi by its own generation and
nothing migrates V1/V2; Blobbi Pixel understands only V3 and would draw a V1/V2 Blobbi as an unrelated creature (it
imports none yet). The "local world form" (a derived, clearly labelled, never-published pixel form, with the original
shown alongside) is **recommended** over a full V1/V2 pixel renderer, after the owner and the kit maintainer agree on
the mapping. Nothing was implemented; no canonical identity or generation changed.

Measured back to back in node (`tsx`, best of 5×120 frames, 1280×720, same machine): a full-screen menu 5.6 ms (was
3.6 ms) — the world is paused while a menu is open; the play frame with the HUD 2.0 ms (unchanged). No per-frame
network, no translation work in the simulation's state, HUD cards cached by language and text size.
